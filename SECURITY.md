# Security Policy

## Privacy & Security First

**Spy Pro** is built with strict privacy and security standards:
- 100% offline data handling via local `chrome.storage.sync` and `sessionStorage`.
- Zero telemetry, zero analytics tracking, zero external network requests.
- Runs with minimal permissions required for browser fullscreen management.

## Reporting a Vulnerability

If you discover a potential security issue in Spy Pro, please report it responsibly by contacting the maintainer:

- GitHub Security Advisories or Issues: [https://github.com/posathanmai1-lang/spy-pro/issues](https://github.com/posathanmai1-lang/spy-pro/issues)

Thank you for helping keep Spy Pro safe for everyone!
